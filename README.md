# Roll20 Alien Typhon Automation

Tools and scripts to automate NPC creation for Alien RPG in Roll20
using Markdown-based NPC files and an API script.

**First Goals**
- Import NPCs from `.md` to the official Alien sheet in Roll20
- Automate NPC creation for the "In Search of Typhon" campaign
- Prepare for Codex integration and iterative development
